Решение рекурсивное. Если root1 null - возвращаю root2 (там, где одно дерево пустое, берём непустое). Если root2 null - возвращаю root1. Если оба существуют - складываю значения в root1.val и рекурсивно сливаю левые и правые поддеревья, записывая результат обратно в root1.left и root1.right. Возвращаю root1.



Идея: идём по обоим деревьям одновременно. Когда оба узла есть - суммируем, когда только один - просто берём его как есть. Новое дерево переиспользует узлы root1, чтобы не выделять лишнюю память.



Сложность - O(n) по меньшему из деревьев или O(n+m) по всем узлам; каждый узел посещается один раз, внутри O(1) работы. Стек рекурсии - O(h). Улучшение - итеративная версия через стек, но при 2000 узлах рекурсия безопасна.
