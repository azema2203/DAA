Решение рекурсивное. Если узел null - выхожу. Иначе сначала иду в левого ребёнка, потом в правого, и только в конце добавляю значение узла в result. Список передаётся по ссылке, поэтому добавления из traverse видны в основном методе.



Postorder - порядок «лево -> право -> узел», узел добавляется последним, после обоих поддеревьев. Это зеркальная противоположность preorder.



Сложность - O(n), traverse вызывается один раз на узел, внутри O(1) работы. Стек рекурсии - O(h). Улучшение - итеративная версия с явным стеком и переворотом результата, но при 100 узлах рекурсия безопасна.
