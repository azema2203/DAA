Решение рекурсивное. Если узел null - возвращаю null. Иначе меняю местами левого и правого ребёнка через временную переменную temp, потом рекурсивно вызываю invertTree для нового левого и нового правого поддерева, и возвращаю root.



Идея простая: зеркальное отражение - это на каждом узле поменять детей местами и рекурсивно отразить оба поддерева. После обхода всех узлов дерево полностью зеркально.



Сложность - O(n): каждый узел посещается один раз, внутри O(1) работы (обмен ссылок + два вызова). Стек рекурсии - O(h). Улучшение - итеративная версия через очередь (BFS) или стек: обходим узлы и меняем детей на месте; та же сложность, но защищает от StackOverflowError на глубоких деревьях. При 100 узлах рекурсия безопасна.
