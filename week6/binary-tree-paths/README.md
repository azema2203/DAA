Решение рекурсивное. Передаю в buildPath текущий узел, строку path (путь до этого узла) и общий список result. Если узел null - выхожу. Иначе добавляю значение узла к path через "->" (или просто значение, если path пуст). Если это лист - добавляю готовый path в result и выхожу. Иначе рекурсивно иду в левого и правого ребёнка с обновлённым path.



Идея: путь «строится» сверху вниз, и когда доходим до листа - сохраняем накопленную строку. Строки в Java неизменяемы, поэтому каждый рекурсивный вызов получает свою копию path - ветки не мешают друг другу.



Сложность - O(n) по узлам, но с учётом построения строк итог O(n·h) или O(n²) в худшем случае из-за конкатенации. Стек рекурсии - O(h). Улучшение - использовать StringBuilder с откатом при возврате, чтобы избежать лишних копий строк. При 100 узлах разница несущественна.
