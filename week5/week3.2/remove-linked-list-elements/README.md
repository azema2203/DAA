&#x20;Remove Linked List Elements



&#x20;Что делаю



Удаляю из списка все узлы со значением val.



&#x20;Алгоритм (через dummy-узел)



1\. Создаю фиктивный узел dummy перед головой. Он нужен, чтобы удобно удалять узлы в начале списка.

2\. Ставлю current = dummy.

3\. Пока current.next != null:

&#x20;  - Если current.next.val == val - удаляю: current.next = current.next.next. Указатель не двигаю (вдруг следующий тоже надо удалить).

&#x20;  - Иначе - двигаю current = current.next.

4\. Возвращаю dummy.next - это новая голова.



&#x20;Почему dummy



Без него пришлось бы отдельно обрабатывать случай, когда удалять надо саму голову (например, \[7,7,7,7] при val=7). С dummy голова - такой же узел, как и все.



&#x20;Почему смотрю на current.next



Чтобы удалить узел, нужно переставить ссылку next у предыдущего узла. Ссылки на предыдущий у нас нет - поэтому мы "стоим на предыдущем" и решаем судьбу следующего.



&#x20;Time Complexity



O(n)



&#x20;Space Complexity



O(1) - только указатели, новых узлов (кроме dummy) не создаю.



&#x20;Почему так



Итераций не больше n: либо удаляю узел, либо двигаюсь вперёд. Память константная.



&#x20;Можно ли лучше



Нет, это оптимально. Рекурсивное решение хуже по памяти (O(n) стека).



&#x20;Крайние случаи



\- Пустой список -> null 

\- Все узлы равны val -> null 

\- Ни один не равен val -> исходный список
