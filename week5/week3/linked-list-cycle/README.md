Linked List Cycle



\- Как я решала



Применила алгоритм Флойда (черепаха и заяц, tortoise and hare).



\- Алгоритм



1\. Стартуем два указателя с головы: slow идёт на 1 узел за шаг, fast - на 2 узла.

2\. Если цикла нет - fast рано или поздно дойдёт до null, возвращаем false.

3\. Если цикл есть - оба указателя попадут внутрь цикла, и fast начнёт догонять slow изнутри. Так как разница в скорости - 1 узел за шаг, они обязательно встретятся.

4\. Как только slow == fast - возвращаем true.



\- Time Complexity



O(n), где n - количество узлов.



\- Space Complexity



O(1) - только два указателя.



\- Почему такая сложность



Без цикла: fast проходит весь список -> O(n).



С циклом: пусть μ - узлов до цикла, λ - длина цикла. slow входит в цикл за μ шагов, дальше fast догоняет его не более чем за λ шагов. Итого μ + λ ≤ n → O(n).

\- Один узел с циклом на себя -> встреча на первом шаге -> true
