&#x20;Merge Two Sorted Lists



\- Как я решала



Использовала классический подход two-pointer merge (тот же приём, что в merge sort, но для связанных списков).



\- Алгоритм



1\. Создаю фиктивный узел dummy - это якорь результата, чтобы не обрабатывать отдельно случай с первым узлом.

2\. Указатель current всегда смотрит на последний узел собранного результата.

3\. На каждом шаге сравниваю list1.val и list2.val, присоединяю меньший узел к current.next, двигаю указатель того списка, откуда взяла узел.

4\. Когда один список закончился - второй уже отсортирован, присоединяю его целиком за O(1).

5\. Возвращаю dummy.next - это настоящая голова результата.



\- Time Complexity



O(n + m), где n - длина list1, m - длина list2.



\- Space Complexity



O(1) - только несколько указателей, новые узлы не создаются.



\- Почему такая сложность



Цикл выполняется максимум n + m раз: каждая итерация съедает ровно один узел из одного из списков. Внутри - O(1) работы.
