&#x20;Remove Duplicates from Sorted List



&#x20;Что делаю



Убираю дубликаты из отсортированного списка. Так как список отсортирован, одинаковые значения всегда стоят подряд - это сильно упрощает задачу.



&#x20;Алгоритм



1\. Ставлю указатель current на голову.

2\. Пока есть current и current.next:

&#x20;  - Если current.val == current.next.val — удаляю дубликат: current.next = current.next.next. Указатель не двигаю (вдруг следующий тоже дубликат).

&#x20;  - Иначе - двигаю current вперёд.

3\. Возвращаю head (голова не меняется, первое вхождение всегда остаётся).



&#x20;Time Complexity



O(n) - прохожу каждый узел один раз.



&#x20;Space Complexity



O(1) - только один указатель, новых узлов не создаю.



Почему так



На каждой итерации либо удаляю узел, либо двигаюсь вперёд. Значит шагов не больше n. Память константная - просто переставляю ссылки.



&#x20;Можно ли лучше



Нет, это оптимально. Сортировка даёт возможность обойтись без HashSet (иначе была бы память O(n)).



&#x20;Крайние случаи



\- Пустой список -> null 

\- Один узел -> он же 

\- Все одинаковые \[1,1,1] -> \[1]
